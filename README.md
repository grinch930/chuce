# 出册 · 跃然纸上

> 每一本书，都有人等待你翻开。

《出册》是一本会动的 AI 立体书。翻开书，角色从插画里立起来，身后的世界随之展开；轻触、长按、画圈，就能和它互动。书中每个角色都由 **Aholo Lux3D** 用一张插画或照片「图生 3D」，再折进网页里的书页。

参赛作品：群核科技 Aholo 全球 3D AI 黑客松

- 在线体验：https://magiclibrary-xi.vercel.app/
- 本地运行：`static/` 就是完整的网站，任意静态服务器都能打开，例如 `cd static && python -m http.server 8000`

## 玩法

**书房书案**：夜里的魔法书房，五本书摊在书案上。鼠标悬停时封面会轻轻掀起；点窗外可以对流星许愿，许完一颗星会落进某本书里。台灯、灯笼、浑天仪、窗台的花都能点。

| 书 | 角色 | 互动 |
|---|---|---|
| 山海图录 | 九尾狐 · 狰 · 应龙 | 展九尾；长按应龙祈雨；**封印狰**：狰冲出书页，一笔画圈把它困进金笼 |
| 爱丽丝漫游奇境 | 爱丽丝 | 「来一口」变大、「deepdrink」变小，坠入兔子洞 |
| 小王子 | 小王子与狐狸 | 风吹麦浪，驯养一只狐狸 |

**书坊**
- **入书**：选一组现成人物（画地为牢 · 许飞 & 厉娜、机器人之梦、小王子与爱丽丝），他们走进书页，与书中角色贴贴、留影；两人一组还能「画地为牢」。也可以上传自己的全身照入书。
- **神笔马良**：随手画一只小动物，生成立体形象，装订成一本属于你的新书，再从书页里走出来。

**第一视角的手**：右手捏书角翻开，左手按住书页翻页，食指轻点角色。

## 技术

- **Aholo Lux3D**：所有角色都由插画或照片图生 3D。线上通过中转服务调用 `img-to-3d` 接口，API Key 只存在服务端环境变量里
- **three.js**：书本开合、翻页、出册 / 入册的折纸动画；角色先以浮雕形态贴合图版，再立起来；顶点着色器驱动呼吸、摆动和头部跟随
- **部件动画**：狰被拆成头、躯干、前腿、尾巴，由代码驱动扑击和挣扎；带骨骼的角色直接播放动作
- **画面**：手绘纸景分层、每本书各自的世界背景、书房夜景和流星（按窗格天空遮罩绘制）
- **声音**：每个场景一首背景音乐，切换时交叉淡化；翻书、出册、入册用真实录音，其余为 WebAudio 合成
- **体积**：模型经 gltf-transform 压缩（减面、WebP 贴图、meshopt），单个 0.6–2MB；字体按用字裁剪后自托管，国内网络无需外部资源

## 目录

```
static/            前端：index.html、main.js、sound.js、assets/、vendor/
app.py             FastAPI 中转服务：托管 static/，代理 Lux3D 图生 3D（限流、轮询、下载）
Dockerfile         魔搭创空间 Docker 部署（端口 7860）
requirements.txt   Python 依赖
DEPLOY.md          部署说明
```

## 运行中转服务

```bash
pip install -r requirements.txt
LUX3D_MOCK=1 python app.py            # 模拟模式，不消耗额度
AHOLO_API_KEY=你的Key python app.py    # 真实调用
# 浏览器打开 http://localhost:7860
```

> 不要把 API Key 写进代码或提交到仓库。
